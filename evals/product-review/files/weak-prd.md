# Community Hub PRD

## Overview
Community Hub is a modern, intuitive platform that brings people together. It will be fast, simple, and delightful for everyone.

## Users
- Members
- Leaders
- Volunteers
- Visitors
- Staff

## Features
- Dashboard with widgets
- Messaging
- Events calendar
- Groups
- Notifications
- Profile pages
- Analytics for leaders

## Goals
- Increase engagement.
- Grow the community.
- Make communication easier.

## Tech
Build it in React with a Node backend and Postgres.
